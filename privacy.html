Privacy Policy

Last updated: November 15, 2026

Clipador is a private tool used only by its owner to manage the owner's own YouTube channels.

What data is accessed

With the owner's permission (Google OAuth), the tool uses the YouTube Data API and YouTube Analytics API to upload videos, set their titles, descriptions, thumbnails, captions and publishing schedule, and read basic statistics of the owner's own channels.

How data is stored

Access tokens are stored only on the owner's own computer. No data is sent to any other server, sold, or shared with third parties.

Other users

The tool has no other users and does not collect data about anyone else.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
